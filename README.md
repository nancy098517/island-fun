更新後頁尾會顯示「分頁自訂版 2026.10.24-r13」。

## 操作分頁

先選模式，再使用同一組四個分頁：

- 玩遊戲：出發縣市、目的縣市、抽選、骰子和冒險事件。
- 看地圖：城市冒險的全部景點；其他模式的店家位置查詢與候選清單。
- 自訂地點：修改目前模式的地點；各縣市或午餐校區分開保存。
- 行程分享：複製、開啟 Gemini、下載 Travel Plan、分享、重玩。

切換分頁不會清除進度。切換模式會回到玩遊戲。

## 城市冒險的自訂地點

22 縣市皆可自訂 8 個不同地點及美食／文化／購物類型。改名會清除原座標，避免沿用舊位置。可以按「查詢位置」從搜尋結果選取正確店家，或貼入緯度與經度；也可以先只填名稱。沒有座標的地點照常參與遊戲、行程和 AI 提示，但會標示「未定位」，不會捏造地圖標記。

「套用地點並重玩」會清除目前縣市的冒險進度，需先確認。其他縣市不受影響。「恢復此縣市預設」回復原本的 8 站。名稱、座標、遊戲抽選、地圖清單和 Travel Plan 同步更新。

## 午餐吃什麼？

預設中科大三民校區，保留 Nancy 提供的 16 個選項。「熹湯鋪子【台中中華店】」名稱及臺中市北區中華路二段 88 號地址依提供的截圖更正；舊名稱會同步更新，其他選項不變。另可選中科大民生、中興大學、東海大學、逢甲大學、彰師大進德、彰師大師大校區（原寶山）。每個校區的自訂清單、抽選進度、搜尋範圍與 AI 行程分開保存，重開網頁保留上次所選校區。

其他學校的初始清單為 16 種餐點類型，並非已核實的附近餐廳名單；可以自行換成常去的店家。彰師大校區名稱依官方網站 https://www.ncue.edu.tw/p/412-1000-865.php?Lang=zh-tw 。

## 午餐與自訂店家的 OpenStreetMap

按「在地圖標示」會切換到看地圖。查詢店名或完整地址，選取正確搜尋結果後標示；不是自動採用第一筆。位置選擇存在目前瀏覽器，AI 提示會附上已確認座標。也可手動貼上「緯度, 經度」。

搜尋使用 Photon 公開展示服務（https://github.com/komoot/photon），僅在使用者按下查詢時呼叫，限制頻率並快取結果，不進行大量或背景掃描。展示服務可能限流或暫停；大量流量請改用自架或有配額的地理編碼服務。未使用 OSM 公共 Nominatim API。OSM 資料未必收錄所有店家；查無資料時改輸入完整地址或座標，不會以附近同名店代替。

底圖與地點資料 © OpenStreetMap contributors（https://www.openstreetmap.org/copyright），以瀏覽器正常快取載入目前可見範圍，不預抓其他圖層。地圖顯示用途不代表營業或道路可通行。

## AI 與下載

已移除 AI 行程設定表單，也不會讀取舊設定。提示只帶入目前出發地及選定地點，請 AI 建議天數並確認交通方式。

「複製行程 → 開啟 Gemini」先複製提示，再開啟 Gemini。仍須手動貼上並送出；沒有使用 Gemini API，不會自動登入、貼上或送出。剪貼簿無法使用時會顯示可手動複製的文字。

城市冒險可下載含地理底圖與已定位標記的 Travel Plan。其他模式可在網站上查詢 OSM 地理位置，下載仍為文字行程卡。兩者均支援方形與限動尺寸，底圖載入不全時不提供地理圖下載。

交通卡只是遊戲效果，不提供真實班次或交通路線連結。高鐵限符合出發／目的縣市的西部站點。精確行程可複製交給 AI，出發前仍請核對位置、營業與時間。

瀏覽器儲存僅限目前裝置；請在清除網站資料前先下載或複製。網站可直接透過 GitHub Pages 提供靜態檔案，不需要 API 金鑰。
