# 島遊趣｜完整版

## 上傳到原本的 GitHub Pages
1. 解壓縮 island-fun.zip。
2. 打開其中的 island-fun 資料夾。
3. 將資料夾「裡面的檔案與 assets」上傳到 GitHub 原網站的相同位置，覆蓋同名檔案。
4. 務必包含 index.html、style.css、game.js、explore.js、transport.js、place-map.js，以及完整 assets 資料夾。
5. 不要只上傳 ZIP，也不要多套一層 island-fun 資料夾。
6. 等待 GitHub Pages 部署完成後重新整理。首頁應看到五個玩法入口與 Google Maps。

程式不需要 npm、建置或 Google API 金鑰。Google 地圖需連網；瀏覽器限制、網路或廣告攔截可能影響嵌入顯示，可用「在 Google Maps 開啟」查看。

## 五個玩法入口
- 遊台灣：從全台景點抽下一站。
- 選縣市玩：可手動選 22 縣市，或用骰子／模擬飛鏢／輪盤先抽縣市，再抽當地景點。
- 中科大午餐：三民、民生校區分開保留紀錄，預設 16 個使用者提供的餐點／店家選項。可每行輸入一個，自訂整份午餐地圖，亦可恢復預設。
- 自訂抽籤：每行一個選項，設定抽出數量（預設 1），按「開始抽籤」。重複名稱合併，同次不重複抽選；每輪開始時重新納入所有候選。
- 經典環島棋盤：擲骰移動、景點蓋章、奇遇／突發事件及結算。

午餐預設（名稱依使用者原文保留）：
礁溪柯家蔥油餅、熹湯舖子、好家木瓜牛奶、縱卝公滷、京燉滷味、健身舒肥水煮餐盒、泓維便當店、cama、露易莎、星巴克、蓮尾一鳴 豚骨拉麵專門店、春水堂、童話樹簡餐廳、麥當勞、Subway、Sukiya。

## 自訂地圖
- 遊台灣／縣市：展開「自訂這張地圖的地點」，每行貼一個地點，按「套用到這張地圖」，即可替換候選地點，之後只會抽這份清單。
- 午餐：編輯選項後儲存即可改變午餐抽選內容。
- 經典棋盤：在「我的旅行行程」選擇要替換的格子，輸入新地點後按「替換地圖格子」。
- 更新地圖會重新開始該地圖目前的抽選／回合紀錄，已有紀錄時會先確認；其他地圖的紀錄保留。
- 探索棋盤為候選清單，並非地理位置。各縣市與校區有各自的行程，不重複抽已選地點。可移除地點讓它重新成為候選。
- 骰子使用六進位編碼對應候選編號，各候選等機率；不是傳統骰子步數加總。飛鏢為模擬隨機抽選，不是手動瞄準遊戲。

## Google Maps 與分享
- 共用一張內嵌 Google 地圖，一次標示目前抽到／點選的地點。
- 點候選格子或行程的「在地圖標示」，即可切換到該地點。
- 暫不提供交通規劃、捷運／公車轉乘連結，也不繪製交通路線。
- 「複製地圖連結」複製目前地點的 Google Maps 網址。
- 「複製邀約文字」包含完整行程與各地點 Google Maps 連結。
- 「分享給朋友」在支援的裝置開啟系統分享選單；不支援時改用複製文字。程式不會自動發文。
- 「下載分享圖 PNG」提供方形 1080×1080、IG 限動 1080×1920。圖片為行程卡，不是 Google 地圖截圖。方形最多呈現 5 站，限動最多 12 站；更多地點提示查看完整文字。
- 分享至 FB／IG 時自行選擇下載的圖，並貼上邀約文字。限動連結請自行用平台的連結貼紙加入。
- 名稱搜尋可能遇到同名地點或分店，請確認位置；跨縣市與離島請另行分天安排。抽選行程尚未依距離最佳化。

## 出發列車與交通遊戲卡
- 遊台灣／縣市：選遊戲出發縣市，首次抽景點時自動抽交通卡。之後依上一站縣市抽出交通卡，保留在紀錄及複製行程中。
- 經典棋盤：第一回合落點後先顯示出發交通卡，再顯示景點或事件卡。新自強號 +10 旅遊值、鳴日號 +20、高鐵 +15；在地／公路接駁 +5，海空交通 +10。
- 高鐵只出現在不同縣市、兩端皆為西部高鐵站所在縣市的區間；高雄端標示左營站。東部、屏東、南投、離島不抽高鐵直達卡。
- 新竹市／嘉義市跨縣市接駁至高鐵站未自動推算，這版採保守條件。
- 鳴日號是觀光套裝行程。卡片是遊戲體驗，不表示隨到隨搭或實際在抽到景點停靠。
- 午餐與一般自訂抽籤不抽列車。自訂景點縣市無法辨識時，只給在地接駁卡。

## 儲存與離線
- 使用同一個瀏覽器時自動儲存選項及已完成的紀錄。換裝置、清除網站資料、無痕或停用儲存會影響保存。
- 經典環島若在回合中離開，下次回到上個完成回合。
- 可用瀏覽器直接開 index.html 試玩；正式使用建議 GitHub Pages，儲存、剪貼簿與地圖顯示較穩定。
- 程式與素材均包含在 ZIP；Google 地圖及線上字體需網路。另附本機中文字體支援分享圖的中文渲染。
