## r21 行程收尾

六種玩法的遊戲區都有「結束行程／下載行程／AI 排行程」。結束會停止目前城市、地圖／校區或這輪抽選，保留已走訪／已抽出的地點，並切到行程與下載；未實際走訪的目標不加入。經典棋盤可提前結束，不會假稱已完成環島。結束狀態會儲存，可按重玩開始新行程。

下載入口會切到行程與下載，選擇圖片尺寸後按下載；新增完整行程清單預覽與「下載 AI 排程文字」（travel-plan-ai.txt），不受圖片顯示地點數上限影響。地理底圖未載入時仍可下載文字。AI 入口使用本次已選地點，不會混入所有候選；原有出發地、座標和地點搜尋連結一併帶入提示，要求重新排序。仍需自行貼到 Gemini 並送出，開啟前會提示。

## r20 巷口小吃連到附近美食

適用全部 22 縣市與城市冒險的自訂景點。到站時可按「查這站附近美食」。新取得的小吃與市集小吃，會儲存它對應的景點編號；點背包中的小吃，即開啟 Google Maps，以「縣市＋當時景點＋附近美食 小吃」搜尋。後續走到別站也不會改變原小吃的搜尋中心。

舊存檔缺少當時位置，保留原文字並標示未保留景點，只做縣市美食搜尋。遊戲收藏不是實際店家或已消費紀錄；此功能在 Google Maps 顯示搜尋結果，不會在網站內捏造餐廳、評分或營業狀況。不需要使用者提供定位、API 金鑰或交通路線。
